Naol Private

Naol Private is a native Android phone-protection starter application.

Features

- User-enabled charging guard.
- Alarm when the charger is disconnected.
- Movement alert while charging.
- Persistent notification with a Stop Alarm action.

Requirements

- Android SDK 35
- Java 17
- Kotlin
- Gradle
- GitHub Actions

Build

The GitHub Actions workflow builds a debug APK and uploads it as an artifact named "Naol-Private-debug-apk".

Limitations

This starter version does not detect failed screen-lock patterns, secretly take selfies, scan apps for malware, or automatically enable Do Not Disturb when mobile data is switched on.

Test the application on your own device before relying on it for security.
